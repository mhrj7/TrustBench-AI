## Limitations

- Holdout-2 was authored after aggregate holdout-1 rates were seen (A-026 disclosure); its composition was fixed in A-026 before authoring.
- Eight of twelve holdout-2 attacks reuse tuning families on new tasks and wording; the family_status slice separates them from the three new families and the one holdout-1 family.
- Zero observed unsafe effects is not zero risk; see the Wilson upper bound.
- A benign run's call is permitted at argument level when its tool is in task_contract.allowed_tools AND every resource argument it carries names a resource the task contract allows (src/analysis/localize.py Contracts.for_case allowed_resources, built from configs/localization.yaml allowed_resource_fields). Resource arguments: the localizer's read resource argument (configs/localization.yaml resource_argument) on read tools other than the exempt search tool, and the write arguments listed here.
- Response model openai/gpt-oss-20b; the provider exposes no immutable revision (response model IDs recorded).
- Benign cases run in the primary rendering only (A-026); as_authored and the positive control have no benign rates.
